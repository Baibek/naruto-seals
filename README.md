# Ниндзя мөрлері — веб-камера арқылы қол мөрлерін тану

Бір файл: `index.html`. MediaPipe Tasks Vision (HandLandmarker + ImageSegmenter) CDN арқылы жүктеледі.

## Іске қосу

```bash
cd naruto-seals
python -m http.server 8000
```

Браузерде http://localhost:8000 мекенжайын ашып, «Камераны қосу» батырмасын басыңыз.
Файлды `file://` арқылы ашпаңыз: браузер онда камераға рұқсат бермейді. Модельдерді жүктеу үшін интернет қажет.

## Үйрету

1. Оң жақтағы тордан мөрді таңдаңыз.
2. Қолыңызды сол мөрдің қалпына қойып, `Space` пернесін басып тұрыңыз (немесе «Жазу» батырмасын).
3. Әр мөрге 80–150 үлгі жазыңыз. Жазу кезінде қолды сәл жылжытып, бұрып, камерадан алыс-жақын қылыңыз.
4. Дерек localStorage-да сақталады. Сақтық көшірме үшін «Экспорт JSON» батырмасын басыңыз.

## Техникалар (10)

| Техника | Тізбек | Эффект |
|---|---|---|
| Каге Бунсин но Дзюцу | Крест | Түтін ішінен 4 клон шығады |
| Катон: Гоукакюу | Жылан → Қошқар → Мешін → Доңыз → Жылқы → Жолбарыс | Үлкен от шары |
| Чидори | Сиыр → Қоян → Мешін | Алақандағы найзағай |
| Катон: Хоосенка | Тышқан → Жолбарыс → Ит → Сиыр → Қоян → Жолбарыс | Жарылатын кішкентай от шарлары |
| Катон: Рюука | Жылан → Айдаһар → Қоян → Жолбарыс | Қолдан шыққан от ағыны |
| Фуутон: Дайтоппа | Жолбарыс → Сиыр → Ит → Қоян → Жылан | Күшті жел толқыны |
| Дотон: Дорюухеки | Жолбарыс → Қоян → Доңыз → Ит | Жерден тас қабырға көтеріледі |
| Суйтон: Суйрюудан | Сиыр → Мешін → Қоян → Тышқан → Доңыз → Тауық | Су айдаһары (анимедегі 44 мөрдің алғашқы 6-уы) |
| Кучиёсе но Дзюцу | Доңыз → Ит → Тауық → Мешін → Қошқар | Шақыру мөрі мен үлкен түтін |
| Хенге но Дзюцу | Ит → Доңыз → Қошқар | Адам алтын чакраға боялады |

Тізбек икемді: арасында қате мөр танылса да, керекті мөрлер ретімен кездессе болғаны.
