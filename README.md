# Ниндзя мөрлері — веб-камера арқылы қол мөрлерін тану

Бір файл: `index.html`. MediaPipe Tasks Vision (HandLandmarker + ImageSegmenter) CDN арқылы жүктеледі.

## Іске қосу

```bash
cd naruto-seals
python -m http.server 8000
```

Браузерде http://localhost:8000 мекенжайын ашып, «Камераны қосу» батырмасын басыңыз.
Файлды `file://` арқылы ашпаңыз: браузер онда камераға рұқсат бермейді. Модельдерді жүктеу үшін интернет қажет.

## Үйрету

1. Оң жақтағы тордан мөрді таңдаңыз.
2. Қолыңызды сол мөрдің қалпына қойып, `Space` пернесін басып тұрыңыз (немесе «Жазу» батырмасын).
3. Әр мөрге 80–150 үлгі жазыңыз. Жазу кезінде қолды сәл жылжытып, бұрып, камерадан алыс-жақын қылыңыз.
4. Дерек localStorage-да сақталады. Сақтық көшірме үшін «Экспорт JSON» батырмасын басыңыз.
