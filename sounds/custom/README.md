# Өз дыбыстарыңыз

Бұл бумаға өзіңіздің MP3 файлдарыңызды салсаңыз, бағдарлама стандартты дыбыстардың орнына соларды ойнатады.

1. Файлды техника атауымен сақтаңыз (төмендегі тізім).
2. Атауын `list.json` ішіне жазыңыз, мысалы: `["chidori", "fire", "seal"]`.
3. Бетті жаңартыңыз.

| Файл | Қашан ойнайды |
|---|---|
| `seal.mp3` | Мөр танылғанда |
| `clones.mp3` | Каге Бунсин но Дзюцу |
| `fire.mp3` | Катон: Гоукакюу |
| `chidori.mp3` | Чидори |
| `hosenka.mp3` | Катон: Хоосенка |
| `ryuka.mp3` | Катон: Рюука |
| `daitoppa.mp3` | Фуутон: Дайтоппа |
| `doryuheki.mp3` | Дотон: Дорюухеки |
| `suiryudan.mp3` | Суйтон: Суйрюудан |
| `kuchiyose.mp3` | Кучиёсе но Дзюцу |
| `henge.mp3` | Хенге но Дзюцу |

Бұл бумадағы MP3 файлдар `.gitignore` арқылы GitHub-қа жүктелмейді.
Авторлық құқықпен қорғалған дыбыстарды тек жеке пайдалануға қолданыңыз және оларды жарияламаңыз.
